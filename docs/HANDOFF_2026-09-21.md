### 3.2 本地 API

文件：

- `server.py`
- `start-server.ps1`
- `data/state.json`

当前 API：

```text
GET  /api/health
GET  /api/cases
POST /api/cases
GET  /api/samples
POST /api/samples
GET  /api/analysis/jobs
POST /api/analysis/jobs
POST /api/analysis/jobs/:id/cancel
GET  /api/evidence/:caseId
POST /api/evidence
POST /api/evidence/:id/review
POST /api/copilot/messages
GET  /api/toolchain/health
POST /api/reports
GET  /api/reports/:id/download
GET  /api/audit
```

安全特性：

- 默认绑定 `127.0.0.1`。
- `create_server()` 拒绝非 loopback 绑定。
- 拒绝非本机 Host。
- 拒绝跨站 Origin / `Sec-Fetch-Site: cross-site`。
- health 返回临时会话 token。
- POST 必须带 `X-ReverseAI-Token`。
- 请求体严格限制为 JSON，大小上限 1 MB。
- SHA-256 必须是 64 位十六进制字符串。
- 样本接口只接收元数据，不读取路径，不接收二进制正文。
- `metadata_check` 只检查登记元数据。
- 其他真实分析任务默认为 `blocked`，不会执行样本或工具。
- 报告创建时冻结快照并计算 SHA-256。
- 审计日志使用前序哈希链。

### 11.8 证据与报告页面专项修复

用户反馈包括但不限于节点框无法移动、文字错位、线条错误且僵硬、人工复核文本框颜色突兀。源码及浏览器确认：

- 节点是固定百分比定位的 `span`，尺寸固定 92×54，没有拖动／平移／缩放实现。
- `.node small` 使用 `margin-top:-14px`，标题和说明缺少稳健排版；长字段、不同宽度／缩放下的错位需进一步专项复现和验收。
- 连线为 3 个绝对定位的 `.linkline`，使用固定宽度及旋转角度，不绑定节点锚点，也不代表真实证据关系。
- 浏览器中的复核 textarea 为白底黑字（`rgb(255,255,255)`／`rgb(0,0,0)`），当前样式没有为其设置主题背景、文字、边框及焦点态。

待办与验收：

1. 建立有来源的节点／边模型，节点可拖动，支持平移、缩放、复位／适应画布及查看原始记录；Case 切换不得串用布局或证据。
2. 连线从节点锚点计算，使用 SVG／画布等动态路径，移动、缩放及窗口变化后实时跟随；清楚表达方向／关系，避免穿过文字、连接错误对象或产生无来源的边。
3. 节点标题、来源、状态和置信说明分层排版；支持换行、截断与完整详情，去除负边距补偿。测试长中文、长哈希、长函数名和大量节点。
4. 人工复核输入框适配深浅主题，统一背景、字体、边框、间距和焦点态；保留草稿，提交中阻止重复操作，错误时保留输入，成功后显示审计结果。
5. 补齐证据创建、筛选／分页、已复核备注展示；报告页展示实际报告记录、格式、生成时间、范围及校验信息，错误和旧版无快照报告有明确提示。
6. 在隔离数据中完成“登记样本 → 元数据检查／人工证据 → 图中定位 → 人工复核 → 三种报告下载”的浏览器端验收；空状态、演示标记和真实执行边界均须一致。
