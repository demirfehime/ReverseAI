## API 配置与模型

访问 `http://127.0.0.1:8787/`，点击顶部 **API 配置** 或左侧 **API 与模型**，新增 Provider，填写 Base URL、协议、API Key 和模型 ID，保存后获取模型列表、选择模型并测试连接。

实现 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 三种文本协议，支持兼容服务、自定义非敏感请求头、超时、真实模型列表及连接测试。模型列表不可用时可手动输入 ID。当前为非流式文本调用，不支持模型自动工具调用。

API Key 在 Windows 使用当前用户 DPAPI 加密，独立保存在状态目录的 `credentials.dpapi`；不写入 `state.json`、浏览器存储或报告。也可填写服务进程的环境变量名。其他系统使用进程内凭据，重启需重新填写。

Copilot 选择“已配置模型”后才调用 Provider；本地规则模式仍可独立使用。请求包含用户输入、当前样本元数据、相关证据和所选 Skill 文本，不上传二进制。消息记录标注 Provider、模型和 Skill 版本。

## 子 Agent

左侧 **子 Agent** 支持父任务与文本子任务、并发/调用次数/时限预算、模型继承或覆盖、Skill 绑定、取消及结果查看。结果以待人工复核证据保存。超时或取消后的迟到输出被丢弃，服务重启不会重发中断请求。当前子 Agent 无工具执行权限；动态执行 worker、Frida 附加和样本执行仍未实现。
